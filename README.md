# 極限組裝大師：Mechanical Overclock

一款精密機械組裝小遊戲：把定位柱和齒輪裝到主機板上，再進行轉速與溫度的過載測試。
整個遊戲寫在單一 `index.html` 裡（HTML + CSS + JavaScript），不需要安裝任何東西。

## ▶ 線上直接玩

**https://jasperc1972-del.github.io/mechanical-overclock-game/**

建議用電腦版 Chrome 或 Edge，用滑鼠操作。

## 一步一步教你玩

### 步驟 1：打開遊戲
- **線上玩**：點上面的網址。
- **在自己電腦玩**：下載這個專案（綠色 **Code** 按鈕 → **Download ZIP**），解壓縮後雙擊 `index.html`。

### 步驟 2：開始畫面
畫面中間有遊戲規則，看完按 **「開始組裝」**。

### 步驟 3：認識組裝畫面

```
┌────────────┬──────────────────────────┬────────────┐
│ ⟲ 重來      │  PHASE  SCORE  TIME  ERRORS │         ✕  │
├────────────┼──────────────────────────┼────────────┤
│  左側零件匣  │        中間：主機板          │  右側零件匣  │
│  （齒輪）    │   L1 ●                    │ （金色定位柱）│
│   Z30       │      S1 ◯  S2 ◯  S3 ◯      │     ●      │
│   Z25       │                    ● L2   │     ●      │
│   Z20 Z15   │                          │     ●      │
└────────────┴──────────────────────────┴────────────┘
```

- **上方計分板**：目前階段、分數、剩餘時間、失誤次數。
- **中間主機板**：5 個孔位。S1、S2、S3 是齒輪主軸，L1（左上角）和 L2（右下角）是固定孔。
- **左側**：4 顆齒輪，中間的數字是齒數（Z30 = 30 齒）。
- **右側**：5 根金色定位柱。

### 步驟 4：裝定位柱（一定要先做）
1. 用滑鼠按住右側的一根**金色定位柱**。
2. 拖到主機板上任一個黑色圓孔。
3. 靠近時孔位會出現光圈，**光圈變綠色**就放開，定位柱會自動吸附上去。
4. 重複到 **5 個孔都裝滿**：S1、S2、S3、L1、L2。

> L1 在主機板左上角、L2 在右下角，最容易漏掉。

### 步驟 5：裝齒輪
1. 按住左側的齒輪，拖到 S1、S2 或 S3 上，光圈變綠就放開。
2. **怎麼選對齒輪**：每根主軸外圍都有一圈**虛線圓**，選大小跟虛線圓一樣的齒輪。
   橘色的 `C 150`、`C 105` 是兩軸的中心距，正確的兩顆齒輪半徑相加剛好等於中心距。
3. 拖曳時齒輪外框如果變**紅色**，代表會撞到已經裝好的齒輪。
4. 放錯會出現：
   - **「干涉」**：齒輪太大，跟旁邊的齒輪撞在一起
   - **「無法嚙合」**：齒輪太小，跟旁邊的齒輪碰不到

   每次放錯扣 50 分，零件會自動彈回零件匣。

> 左邊有一顆齒輪是**陷阱**，裝在哪裡都不對。
> 主軸還沒裝定位柱就放齒輪，會提示你先裝定位柱（不扣分）。

8 個零件全部裝好後，畫面會顯示「組裝完成」，2 秒後自動進入測試。

### 步驟 6：過載測試
畫面右邊會出現 **「過載測試」面板**，由上到下是：

| 項目 | 說明 | 你要做的事 |
|---|---|---|
| **轉速 RPM** 滑桿 | 上方長條的**綠色區域**是目標轉速，白色直線是目前轉速 | 拖動滑桿，讓白線停在綠區裡 |
| **冷卻流量** 滑桿 | 開越大降溫越快，但冷卻液也用越快 | 依溫度調整 |
| **溫度** | 黃線 100°C 是警戒，紅線 120°C 是失效 | 盯著它，不要碰到紅線 |
| **冷卻液存量** | 用完就幾乎無法降溫 | 不要一直開最大 |
| **穩定運轉進度** | 轉速在綠區內才會增加 | 累積到 15 秒就過關 |

注意：
- 綠色目標區**每 6 秒會換位置**，要跟著調整轉速。
- 轉速越高越熱（發熱量與轉速平方成正比）。
- 上方 TIME 會從 60 倒數，時間到還沒完成就算失敗。

### 步驟 7：結果畫面
過關或失敗都會跳出結果畫面，顯示分數明細和最高分，下面有三個按鈕：

| 按鈕 | 作用 |
|---|---|
| **再挑戰** | 馬上重新開始一局 |
| **回主畫面** | 回到開始畫面 |
| **✕ 跳出** | 離開遊戲 |

### 遊戲中隨時可用的按鈕
- **左上角「⟲ 重來」**：重新開始這一局。
- **右上角「✕」**：離開遊戲。畫面會顯示「已離開遊戲」，這時按 `Ctrl + W` 或瀏覽器分頁上的 ✕ 關閉即可。
  （瀏覽器規定網頁不能自己關掉使用者開的分頁，所以最後一步要自己關。）

## 過關 & 失敗條件

| 結果 | 條件 |
|---|---|
| ✅ 通關 | 組裝完成，且測試中轉速在綠區累積 15 秒 |
| ❌ 失敗 | 組裝超過 120 秒 |
| ❌ 失敗 | 組裝失誤 5 次 |
| ❌ 失敗 | 測試中溫度達到 120°C |
| ❌ 失敗 | 測試超過 60 秒仍未完成 |

## 計分

| 項目 | 分數 |
|---|---|
| 每裝好一個零件 | +100 |
| 每次組裝失誤 | −50 |
| 組裝剩餘秒數 | 每秒 +5 |
| 測試中轉速在綠區 | 每秒 +40 |
| 測試中溫度超過 100°C | 每秒 −30 |
| 通關時剩餘冷卻液 | 每 1% +5 |
| 全程最高溫低於 100°C | +300 |

最高分會存在你的瀏覽器裡。

## 高分訣竅
- 先把 5 根定位柱一口氣裝完，再裝齒輪，速度最快。
- 對照表：**S1 → Z30、S2 → Z20、S3 → Z15**（Z25 是陷阱）。
- 測試時冷卻流量開 40～60% 就好，不要一開始就開到最大。
- 綠區跳到高轉速時，把轉速停在綠區的**最左邊**，熱比較少。
- 溫度接近 100°C 時，先把冷卻開大撐過去。

## 給開發者

### 目錄結構

```
mechanical-overclock-game/
├── index.html      遊戲本體
├── README.md       本說明
└── assets/         美術素材（可留空，留空時改用程式繪製的圖形）
```

### 換上自己的美術圖（例如用 Higgsfield 生成）
把圖片放進 `assets/`，檔名如下。找不到的圖會自動用程式繪製的圖形代替。

| 檔名 | 長寬比 | 提示詞範例 |
|---|---|---|
| `background.png` | 16:9 | `dark industrial blueprint background, cyberpunk machine workshop, cyan grid lines, moody lighting, no text, game background` |
| `chassis.png` | 1:1 | `top view of a dark steel machine base plate, industrial, cyberpunk details, bolts and vents, orthographic, solid pure green background #00FF00` |
| `gear.png` | 1:1 | `top view of a single polished steel spur gear, centered, orthographic, high detail, solid pure green background #00FF00` |
| `pin.png` | 1:1 | `top view of a brass cylindrical locating pin, centered, orthographic, solid pure green background #00FF00` |

- 零件圖用**純綠色背景**，遊戲會自動去背；零件本身避免綠色。
- 自動去背需要透過網址開啟（GitHub Pages 或 `python -m http.server 8000` 後開 `http://localhost:8000`）。直接雙擊 `index.html` 時，瀏覽器不允許讀取圖片像素，圖片會帶著綠底顯示。

### 調整難度
`index.html` 的 `<script>` 開頭有幾個常數：

| 常數 | 用途 |
|---|---|
| `ASSEMBLY_TIME` | 組裝時限（秒） |
| `MAX_MISTAKES` | 允許失誤次數 |
| `TEST_GOAL` | 測試要累積的秒數 |
| `TEST_TIME` | 測試時限（秒） |
| `SNAP_DIST` | 吸附距離（像素） |
| `BANDS` | 測試的目標轉速區間清單 |

測試的發熱與冷卻參數在 `updateTest()` 裡。
